# DayGrid - Codebase Context

## Project Overview
DayGrid is a premium task management application with intelligent scheduling, priority management, and anti-cheating mechanisms. The codebase features a sophisticated black/silver themed public landing page with waitlist system and a comprehensive authenticated dashboard for task management.

## Architecture

### Technology Stack
- **Framework**: Next.js 16.1.1 with App Router
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 4
- **UI Components**: shadcn/ui (Radix UI based)
- **State Management**: Zustand + React Context
- **Animations**: GSAP for premium landing page interactions
- **Backend**: Supabase (with mock fallback for development)
- **Package Manager**: pnpm
- **Form Handling**: React Hook Form + Zod validation
- **Drag & Drop**: @dnd-kit for task scheduling

## Core Features

### Landing Page (/)
- Premium black and silver theme inspired by eden.so
- Hero section with GSAP-animated text and effects
- Features showcase (6 core features) with hover animations
- How it works section with step-by-step process
- Waitlist-focused CTA sections with success states
- Responsive navigation with discreet admin access
- Advanced GSAP animations and micro-interactions
- Background effects and premium visual design

### Authentication
- Mock authentication for development (works out of the box)
- Real Supabase integration (configure with .env.local)
- Protected routes via proxy middleware
- Login/signup forms with Zod validation
- Automatic redirects and user session management
- Password visibility toggle and form validation

### Dashboard (/dashboard)
- Comprehensive task creation and management with form validation
- 24-hour scheduling grid with drag-and-drop functionality
- Priority system (1-10 scale) with exclusive high-priority enforcement
- Task types (6 categories: regular, meeting, class, appointment, deadline, commitment)
- Day states (Planning → Active → Completed) with immutable logging
- Advanced drag and drop with @dnd-kit integration
- Real-time analytics, statistics, and progress tracking
- Anti-cheating mechanisms and security monitoring

## Business Logic

### Task System
- **Priority Rules**: Only ONE task can have high priority (7-10) with automatic validation
- **Task Types**: regular, meeting, class, appointment, deadline, commitment (with reschedule rules)
- **Scheduling**: 24-hour grid with business hours enforcement (6:00-22:00) and conflict detection
- **Day States**: Planning (flexible), Active (locked with anti-cheat), Completed (view-only with audit trail)
- **Security**: Immutable logging, anomaly detection, and comprehensive audit trails

### Security Features
- Immutable logging for task changes
- Anomaly detection
- Anti-cheating mechanisms
- Comprehensive audit trails

## Configuration

### Environment Variables (.env.local)
```bash
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
DATABASE_URL=your_database_connection_string
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
```

### Route Protection
- **Public Routes**: /, /auth/login, /auth/signup, /auth/forgot-password, /terms, /privacy
- **Protected Routes**: /dashboard, /dashboard/* (require authentication)
- **Middleware**: Located in src/proxy.ts
