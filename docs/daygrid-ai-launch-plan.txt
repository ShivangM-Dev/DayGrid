FEATURE OVERVIEW
================

FEATURE 1: BASIC ANALYTICS & INSIGHTS
------------------------------------
Goal: Provide users with actionable insights about their productivity
without external services or costs.

Key Metrics:
- Task completion rate (daily/weekly)
- Productivity patterns by time of day
- Task type distribution breakdown
- Priority distribution analysis
- Total focus time calculation
- Weekly trend comparisons

UI Components:
- Weekly completion rate chart
- 24-hour productivity heatmap
- Task type pie chart
- Priority distribution bar chart
- Focus time summary card
- Weekly trends line chart

FEATURE 2: NATURAL LANGUAGE TASK CREATION
-----------------------------------------
Goal: Enable users to create tasks using natural language through
pattern matching (no external AI APIs).

Supported Patterns:
- Time/Date: "tomorrow 2 PM", "Friday morning", "14:00"
- Task Types: "meeting", "deadline", "appointment", "class"
- Priority: "urgent", "asap", "high priority", "low priority"
- Duration: "quick call", "2 hour meeting", "30 min"

Example Inputs:
- "Team meeting tomorrow at 2 PM"
- "Urgent deadline for project due Friday"
- "Quick call with client 30 minutes"
- "Low priority organize files this week"

TECHNICAL IMPLEMENTATION DETAILS
================================

ANALYTICS CALCULATIONS (No External Dependencies)
------------------------------------------------

Completion Rate Formula:
completionRate = (tasksCompleted / (tasksCompleted + tasksFailed)) * 100

Productivity By Hour:
productivityByHour[hour] = count of tasks completed in specific hour

Task Type Distribution:
taskTypeDistribution[type] = percentage of tasks by type

Priority Distribution:
high = count of tasks with priority >= 7
medium = count of tasks with priority >= 4 and < 7
low = count of tasks with priority < 4

Focus Time Calculation:
totalFocusTime = sum of durations for all scheduled tasks

  hour: /(\d{1,2})\s*(?::(\d{2}))?\s*(am|pm|o'clock)?/i,
  // Time phrases: "morning", "afternoon", "evening"
  timePhrase: /(morning|afternoon|evening|night)/i,
  // Relative dates: "tomorrow", "today", "next week"
  relativeDate: /(today|tomorrow|yesterday|next week|last week)/i,

DATABASE SCHEMA EXTENSIONS
--------------------------

Analytics Summary Table:
CREATE TABLE analytics_summary (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  date DATE NOT NULL,
  completion_rate DECIMAL(5,2),
  tasks_completed INTEGER,
  tasks_failed INTEGER,
  total_focus_time DECIMAL(5,2),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

Task Analytics Events:
CREATE TABLE task_events (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  task_id UUID REFERENCES tasks(id),
  event_type VARCHAR(20) NOT NULL, -- 'created', 'completed', 'failed', 'scheduled'
  timestamp TIMESTAMP DEFAULT NOW(),
  metadata JSONB,
  created_at TIMESTAMP DEFAULT NOW()
);

NATURAL LANGUAGE INPUT EXAMPLES:
---------------------------------

Simple Patterns:
"Meeting tomorrow at 2 PM" -> { type: MEETING, time: 14, date: tomorrow }
"Urgent deadline Friday" -> { type: DEADLINE, priority: 9, date: Friday }
"Quick call with client" -> { type: MEETING, duration: 0.5 }
"Low priority organize files" -> { type: REGULAR, priority: 3 }

Complex Patterns:
"Team standup tomorrow morning at 9 AM for 30 minutes"
  -> { type: MEETING, time: 9, date: tomorrow, duration: 0.5 }
"Urgent project deadline due next Friday at 5 PM"
  -> { type: DEADLINE, priority: 9, date: next Friday, time: 17 }
"Appointment with doctor next Monday at 2:30 PM"
  -> { type: APPOINTMENT, date: next Monday, time: 14.5 }

UNSUPPORTED PATTERNS (for future versions):
- "Recurring meeting every Tuesday" (recurring tasks)
- "Block 2 hours for deep work" (focus time blocks)
- "Review presentation before Friday's meeting" (dependencies)
