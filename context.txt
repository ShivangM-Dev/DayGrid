# DayGrid - Codebase Context

## Project Overview
DayGrid is a task management application with intelligent scheduling and priority management. The codebase has been refactored to include a public landing page and authenticated dashboard.

## Architecture

### Technology Stack
- **Framework**: Next.js 16.1.1 with App Router
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 4
- **UI Components**: shadcn/ui (Radix UI based)
- **State Management**: Zustand + React Context
- **Animations**: GSAP for landing page
- **Backend**: Supabase (with mock fallback for development)
- **Package Manager**: pnpm

## Core Features

### Landing Page (/)
- Black and silver theme inspired by eden.so
- Hero section with animated text
- Features showcase (6 core features)
- How it works section
- Testimonials
- Responsive navigation
- GSAP animations for enhanced UX

### Authentication
- Mock authentication for development
- Real Supabase integration (configure with .env.local)
- Protected routes via middleware/proxy
- Login/signup forms with validation

### Dashboard (/dashboard)
- Task creation and management
- 24-hour scheduling grid
- Priority system (1-10 scale)
- Task types (6 categories)
- Day states (Planning → Active → Completed)
- Drag and drop functionality
- Analytics and statistics

## Business Logic

### Task System
- **Priority Rules**: Only ONE task can have high priority (7-10)
- **Task Types**: regular, meeting, class, appointment, deadline, commitment
- **Scheduling**: 24-hour grid with business hours enforcement (6:00-22:00)
- **Day States**: Planning (flexible), Active (locked), Completed (view-only)

### Security Features
- Immutable logging for task changes
- Anomaly detection
- Anti-cheating mechanisms
- Comprehensive audit trails

## Configuration

### Environment Variables (.env.local)
```bash
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
DATABASE_URL=your_database_connection_string
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
```

### Route Protection
- **Public Routes**: /, /auth/login, /auth/signup, /auth/forgot-password, /terms, /privacy
- **Protected Routes**: /dashboard, /dashboard/* (require authentication)
- **Middleware**: Located in src/proxy.ts

### Key Components to Know

#### Landing Page Animations
- `AnimatedText`: Fade in text animation
- `AnimatedCard`: Scale and fade card animation
- `FadeInOnScroll`: Scroll-triggered animations
- `FloatingElement`: Subtle floating animation
- `GradientShift`: Animated gradient backgrounds

#### Authentication
- `useAuth`: Hook for auth state and operations
- Login/signup forms with password visibility toggle
- Automatic redirect after successful auth

#### Dashboard Features
- Task inbox for unscheduled tasks
- Daily grid with drag-and-drop scheduling
- Day status and management controls
- Real-time statistics and analytics

## Database Schema (Supabase)
- **users**: User profiles and preferences
- **tasks**: Task data with scheduling
- **days**: Day states and progress tracking
- **task_logs**: Immutable change tracking

## Notes for Development
1. Mock auth works out of the box for development

3. All components are responsive and mobile-first
4. GSAP animations are optimized for performance
5. State persistence uses localStorage for development
6. Security logging is comprehensive and immutable
